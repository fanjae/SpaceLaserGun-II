# Space Laser Gun, 레이저를 발사하여 행성을 파괴하는 미니게임
<img width="620" height="400" alt="Image" src="https://github.com/user-attachments/assets/53289691-3b20-48a4-9b88-90be348459e0" />

> Unity에서 코루틴을 활용한 몬스터 웨이브 구현 과제 내용을 바탕으로 만든 디펜스 형태의 미니 게임입니다.

## 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | SpaceLaserGun |
| 개발 기간 | 2026.05.28~ 2026.05.28 |
| 개발 인원 | 1명 |
| 개발 환경 | Unity 6.3 (6000.3.7f1), C# |
| 실행 환경 | Windows |
| IDE | Unity Editor, Visual Studio 2022 |

## 실행 방법
1. Unity 프로젝트를 엽니다.
2. Unity Editor에서 Play 버튼을 눌러 실행합니다.

### 구현 기능 
- 터렛 / 포신 회전 구현
- 포탄, 레이저 발사 기능 구현
- 레이저 쿨타임 적용 및 쿨타임 UI 표시
- 코루틴을 활용한 웨이브 생성 및 웨이브 별 행성 수 조절
- 랜덤 위치에서 행성 스폰 및 생성된 행성이 목표 지점으로 이동
- 레이저와 행성 충돌시 행성 제거
- 행성이 터렛이나 포신에 충돌 시 생명 UI 감소 및 Life가 0이 되면 게임 종료

## 조작 방법
| 키 | 기능 |
|:---:|---|
| ← → | 터렛 회전 |
| ↑ ↓ | 포신 회전 |
| Z | 포탄 발사 |
| X | 레이저 발사 |
